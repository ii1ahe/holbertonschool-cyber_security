# 0X03 Cryptography Basics

Exercises for this part of the course. The file table below describes the saved scripts and answers.

| File | What it does |
| --- | --- |
| [0-sha1.sh](0-sha1.sh) | Hashes the supplied text with SHA-1 and saves it to 0_hash.txt. |
| [1-sha256.sh](1-sha256.sh) | Hashes the supplied text with SHA-256 and saves it to 1_hash.txt. |
| [2-md5.sh](2-md5.sh) | Hashes the supplied text with MD5 and saves it to 2_hash.txt. |
| [3-password_hash.sh](3-password_hash.sh) | Adds a random salt to the supplied text and writes a SHA-512 digest. |
| [4-password.txt](4-password.txt) | Saved output from the matching lab password-hash exercise. |
| [4-wordlist_john.sh](4-wordlist_john.sh) | Runs the lab's raw-MD5 wordlist check with John and saves its output. |
| [5-password.txt](5-password.txt) | Saved output from the matching lab password-hash exercise. |
| [5-windows_john.sh](5-windows_john.sh) | Runs the lab's NT hash wordlist check with John and saves its output. |
| [6-crack_john.sh](6-crack_john.sh) | Runs the lab's SHA-256 wordlist check with John and saves the first recovered value. |
| [6-password.txt](6-password.txt) | Saved output from the matching lab password-hash exercise. |
| [7-crack_hashcat.sh](7-crack_hashcat.sh) | Runs the lab's MD5 wordlist check with Hashcat and saves the first recovered value. |
| [7-password.txt](7-password.txt) | Saved output from the matching lab password-hash exercise. |
