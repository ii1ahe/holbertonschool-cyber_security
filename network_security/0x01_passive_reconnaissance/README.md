# 0X01 Passive Reconnaissance

Exercises for this part of the course. The file table below describes the saved scripts and answers.

| File | What it does |
| --- | --- |
| [0-whois.sh](0-whois.sh) | Writes selected WHOIS contact fields for a domain to a CSV file. |
| [1-a_record.sh](1-a_record.sh) | Looks up a domain with nslookup. |
| [2-mx_record.sh](2-mx_record.sh) | Looks up a domain's mail-exchanger records. |
| [3-txt_record.sh](3-txt_record.sh) | Looks up a domain's TXT records. |
| [4-dig_all.sh](4-dig_all.sh) | Requests a domain's ANY DNS response with dig. |
| [5-subfinder.sh](5-subfinder.sh) | Uses Subfinder to collect a domain's subdomains and save the results. |
| [holbertonschool_report.md](holbertonschool_report.md) | Saved reconnaissance notes with IP ranges and network owners. |
