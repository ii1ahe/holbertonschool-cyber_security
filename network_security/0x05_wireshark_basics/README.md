# 0X05 Wireshark Basics

Exercises for this part of the course. The file table below describes the saved scripts and answers.

| File | What it does |
| --- | --- |
| [0-ip_scan.txt](0-ip_scan.txt) | Wireshark filter for ICMP traffic carried by IPv4. |
| [1-tcp_syn.txt](1-tcp_syn.txt) | Wireshark filter for SYN packets without ACK and a small TCP window. |
| [2-tcp_connect_scan.txt](2-tcp_connect_scan.txt) | Wireshark filter for SYN packets without ACK and a larger TCP window. |
| [3-tcp_fin.txt](3-tcp_fin.txt) | Wireshark filter for FIN-only packets with a 1024-byte TCP window. |
| [4-tcp_ping_sweep.txt](4-tcp_ping_sweep.txt) | Wireshark filter matching TCP packets with SYN or ACK set. |
| [5-udp_port_scan.txt](5-udp_port_scan.txt) | Wireshark filter for ICMP destination-unreachable port errors. |
| [6-udp_ping_sweep.txt](6-udp_ping_sweep.txt) | Saved UDP probe filter from the exercise, matching zero length and destination port 7. |
| [7-icmp_ping_sweep.txt](7-icmp_ping_sweep.txt) | Wireshark filter for ICMP echo requests and replies. |
| [8-arp_scanning.txt](8-arp_scanning.txt) | Wireshark filter for ARP requests sent to broadcast or all-zero target hardware addresses. |
