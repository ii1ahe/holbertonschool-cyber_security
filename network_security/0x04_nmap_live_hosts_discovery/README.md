# 0X04 Nmap Live Hosts Discovery

Exercises for this part of the course. The file table below describes the saved scripts and answers.

| File | What it does |
| --- | --- |
| [0-arp_scan.sh](0-arp_scan.sh) | Runs Nmap host discovery using ARP probes. |
| [1-icmp_echo_scan.sh](1-icmp_echo_scan.sh) | Runs Nmap host discovery using ICMP echo requests. |
| [2-icmp_timestamp_scan.sh](2-icmp_timestamp_scan.sh) | Runs Nmap host discovery using ICMP timestamp requests. |
| [3-icmp_address_mask_scan.sh](3-icmp_address_mask_scan.sh) | Runs Nmap host discovery using ICMP address-mask requests. |
| [4-tcp_syn_ping.sh](4-tcp_syn_ping.sh) | Uses TCP SYN probes on ports 22, 80, and 443 for host discovery. |
| [5-tcp_ack_ping.sh](5-tcp_ack_ping.sh) | Uses TCP ACK probes on ports 22, 80, and 443 for host discovery. |
| [6-udp_ping_scan.sh](6-udp_ping_scan.sh) | Uses UDP probes on ports 53, 161, and 162 for host discovery. |
