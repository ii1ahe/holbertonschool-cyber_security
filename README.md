# Cyber Security Exercises

Cybersecurity coursework covering Linux security, hashing, DNS lookups, host discovery, Wireshark filters, and web security exercises. Each folder holds the scripts, answers, or saved results for one topic.

## Folders

- `cybersecurity_basics/`
- `linux_security/`
- `network_security/`
- `web_application_security/`

## Reading and running the exercises

The folders follow the course topics. Bash scripts run with Linux command-line tools; text files hold filters, lab answers, or saved output. Some scripts change system settings or send test traffic, so read the file guide and use the course lab environment for those tasks.
