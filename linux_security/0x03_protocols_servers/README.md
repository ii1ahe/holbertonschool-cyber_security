# 0X03 Protocols Servers

Exercises for this part of the course. The file table below describes the saved scripts and answers.

| File | What it does |
| --- | --- |
| [0-iptables.sh](0-iptables.sh) | Lists iptables rules with counters and line numbers. |
| [1-audit.sh](1-audit.sh) | Shows active lines in the SSH server configuration. |
| [2-harden.sh](2-harden.sh) | Finds world-writable directories on the root filesystem and removes write access for others. |
| [3-identify.sh](3-identify.sh) | Runs a Lynis audit to identify local system issues. |
| [4-nfs.sh](4-nfs.sh) | Lists NFS exports on the supplied server. |
| [5-snmp.sh](5-snmp.sh) | Finds configuration lines containing public in the local SNMP settings. |
| [6-smtp.sh](6-smtp.sh) | Checks the local Postfix TLS security-level setting. |
| [7-dos.sh](7-dos.sh) | Lab traffic-flood exercise using hping3 with TCP SYN packets to port 80. |
| [8-cipher.sh](8-cipher.sh) | Lists TLS ciphers on the target's port 443 using Nmap. |
| [9-firewall.sh](9-firewall.sh) | Adds rules allowing SSH from an address and dropping its other inbound traffic. |
