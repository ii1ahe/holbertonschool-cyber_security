# 0X00 Linux Security Basics

Exercises for this part of the course. The file table below describes the saved scripts and answers.

| File | What it does |
| --- | --- |
| [0-login.sh](0-login.sh) | Shows the five most recent login records, requesting sudo when needed. |
| [1-active-connections.sh](1-active-connections.sh) | Lists TCP and UDP sockets with process and endpoint details. |
| [2-incoming_connections.sh](2-incoming_connections.sh) | Sets UFW to deny incoming traffic by default and allow TCP port 80. |
| [3-firewall_rules.sh](3-firewall_rules.sh) | Lists rules and counters in the iptables security table. |
| [4-network_services.sh](4-network_services.sh) | Lists listening TCP and UDP services with netstat. |
| [5-audit_system.sh](5-audit_system.sh) | Runs a Lynis system audit. |
| [6-capture_analyze.sh](6-capture_analyze.sh) | Captures five packets from any network interface with tcpdump. |
| [7-scan.sh](7-scan.sh) | Runs Nmap host discovery for the supplied target. |
